# 剑桥雅思阅读爬虫 - 设计规格

## 1. 目标

从 laokaoya.com 爬取剑桥雅思4-19所有阅读文章，建立个人词汇-语境语料库。

## 2. 技术方案

- **语言**：Python 3
- **库**：requests + BeautifulSoup
- **并发**：单线程，简单脚本

## 3. 爬取流程

```
入口页 (https://www.laokaoya.com/43981.html)
    │
    ▼
1. 提取所有子链接 → [url, title] 列表
    │
    ▼
2. 逐个爬取文章（每篇间隔2-3秒随机延迟）
    │
    ▼
3. 输出报告（成功数/总数 + 失败列表）
```

## 4. 请求策略

- User-Agent：模拟浏览器
- 延迟：每篇 2-3 秒随机
- 超时：30 秒

## 5. 异常处理

- 单篇失败：记录并继续
- 重试：失败后等5秒重试1次，再失败则跳过
- 连续3次失败同一篇：暂停爬虫

## 6. 文件夹结构

```
剑雅资源库/
├── 剑桥雅思4/
│   ├── 剑桥雅思4 Test 1 Passage 1.txt
│   ├── 剑桥雅思4 Test 1 Passage 2.txt
│   └── ...
├── 剑桥雅思5/
│   └── ...
```

## 7. 文件格式

文件头：
```
# 剑桥雅思4 Test 1 Passage 1
# 来源：https://www.laokaoya.com/20869.html
```

正文：
```
[英文原文第1段]
[英文原文第2段]
...
---
[中文翻译第1段]
[中文翻译第2段]
...
```

英文和中文之间用 `---` 分隔符分开。

## 8. 输出报告格式

```
========================================
  剑桥雅思阅读爬虫完成
========================================

成功: N 篇 / 总数 M 篇
失败: X 篇

----------------------------------------
失败列表:
1. URL - 原因
2. URL - 原因
----------------------------------------

文件保存位置: /path/to/资源库/
========================================
```
